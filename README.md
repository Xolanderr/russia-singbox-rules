# Russia Sing-box Rules

Актуальные правила маршрутизации для [sing-box](https://sing-box.sagernet.org/), автоматически получаемые из проекта [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat).

## Как это работает

Репозиторий автоматически проверяет наличие новых релизов в исходном проекте. После появления нового релиза:

1. Загружается `sing-box.zip` из соответствующего релиза.
2. Архив распаковывается.
3. Файлы `.srs` публикуются как отдельные assets нового релиза этого репозитория.

Таким образом, файлы доступны напрямую без необходимости скачивать и распаковывать архив целиком.

## Источник

Основным источником данных является:

- [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat)

Конвертация правил в формат sing-box выполняется в исходном проекте.

## Использование

Файлы можно скачать из последнего релиза:

```text
https://github.com/Xolanderr/russia-singbox-rules/releases/latest/download/<filename>
```

Например:

```text
https://github.com/Xolanderr/russia-singbox-rules/releases/latest/download/geoip-ru.srs
```

Названия файлов соответствуют названиям файлов в исходном `sing-box.zip`.

## Обновление

Обновление выполняется автоматически с помощью GitHub Actions после появления новых данных в исходном репозитории.
